# Career Lens

Career Lens is an AI-powered web application that compares a resume with a job description and provides insights into how well the candidate matches the position.

## Features

- Upload a resume in PDF format
- Enter a job description
- AI-powered resume and job description analysis
- Identify matching skills and experience
- Highlight areas that may need improvement
- User authentication with Supabase
- Password reset functionality
- Rate limiting for AI analysis

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Authentication: Supabase Auth
- Database: Supabase PostgreSQL
- AI: OpenAI API
- PDF Processing: PDF parsing
- Deployment: Render

## How It Works

1. Create an account or log in.
2. Upload your resume as a PDF.
3. Enter a job description.
4. Career Lens extracts the resume content.
5. The resume and job description are analyzed using AI.
6. The application provides a structured assessment of the candidate's match.
